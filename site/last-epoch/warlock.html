1. マスタリーの特徴・他職との差別化・固有パッシブ

ウォーロック固有パッシブ＆マスタリーボーナス（耐性確保＋呪い数乗算）

アコライトの基本パッシブに 20pt 投資してウォーロックを選択すると、象徴スキル 地獄亀裂（Chthonic Fissure） の解放ルートが開き、以下のマスタリー固有ボーナスを獲得します。

  • 基礎ボーナス①: 火耐性 +35% ＆ 死霊耐性 +35% — 装備厳選を大幅に楽にしつつ、死霊耐性参照ギミック（苦悩・骨響のバルビュータ）の土台になります。
  • 基礎ボーナス②: 敵に付与された呪い（Curse）1 つにつき与ダメージ +4%（more） — 骨の呪い・魂の悪疫・苦悩・衰弱などの呪いを重ねるほど乗算で火力が伸びます。
  • 自動連鎖と耐性変換: 地獄亀裂が自動で「苦悩（Torment）」を撒きつつ「カオスボルト」を誘発し、さらに「悪心の保護（知力比例庇護）」「グリムヒルドの領域（魔炎）」によって少ないクリックで広範囲を制圧できます。

3. ウォーロック固有スキル＆重要ノード（5種）

スキル名クリックで Last Epoch Tools 日本語版のスキル詳細・ノードツリーが開きます。

地獄亀裂 (Chthonic Fissure)

必須主砲設置亀裂＋苦悩＋ボルト誘発

地面を引き裂く緑/炎の亀裂を開き、中の敵を焼きながら霊を放出して「苦悩（Torment：鈍足＋継続死霊ダメ）」を感染させ続けるウォーロックの要です。

重要ノード＆Season 5 運用ポイント
  • 苦悩のクリティカル・死霊耐性スケール: Acid Skin / Acidbane 等と死霊耐性積みを組み合わせることで継続 DoT に高クリティカルが乗ります。
  • 自動カオスボルト＆火炎鞭: 亀裂から自動発射される カオスボルト や、マラトロスの背骨 による火炎鞭化で単体火力も大幅に補えます。

カオスボルト (Chaos Bolts)

連鎖トリガーエンジン火・死霊 / 血液・骨の呪い誘発

螺旋を描いて飛ぶ複数の混沌弾を放つ火＋死霊スペル。自前詠唱でも地獄亀裂からの自動誘発でも強く、「確率で血液抽出・骨の呪いを自動発動」するノードによって画面内の敵を一斉に呪い・爆破します。

冒涜のベール (Profane Veil)

無敵回避＋チャネリング主砲可庇護生成＋Profane Orb

短時間、異界の影へ変貌して敵のヒットを回避しながら移動・反撃できる攻防一体の切り札。Season 5 でも「Hex Flurry / Profane Orb」の攻撃軸として使う専用ビルドのほか、全ウォーロックの緊急防御＆庇護稼ぎに使われます。

死霊の炎 (Ghostflame)

チャネリング / 移動放射可庇護＋炎上・死霊 DoT

前方へ青白い魂炎を吹き続けるチャネリング魔法。「移動しながらチャネリング（Fluidity）」ノードを取れば滑るように敵を焼きながら高速周回でき、「悪心の保護」「ドゥームヘラルド」による被ダメ軽減＋庇護生成も同時に起動します。

魂の宴 (Soul Feast)

呪い敵から庇護＋魔力回収広範囲死霊スペル

呪われた敵から魂の欠片を引き抜き、多大な庇護（ワード）と死霊爆発を起こすスペル。苦悩の輪 型や高コラプション帯の対集団戦における庇護補給手段として優秀です。

4. 最終ビルドで採用されうるアコライト基本スキル（全12種個別解説）

アコライトの基本スキル 12 種（＋共通移動 即時避け）は呪い付与や自動トリガー連携が多いため 1 つずつ整理します。

肉体交換 (Transplant)

必須移動枠ボーンアーマー＋ヘイスト

瞬間移動しつつアーマーバフ・俊足（Haste）を確保し、着地時に骨の呪いや恐怖を自動発動してマスタリー乗算を補助します。

骨の呪い (Bone Curse)

呪いカウント＋自動発動死の刻印 / イルージョン

敵上の呪い数を +1（さらに「死の刻印」併用で実質 2 枠以上の乗算貢献）しながら、カオスボルトによるヒット連鎖時に大ダメージを叩き込む定番の呪文です。

魂の悪疫 (Spirit Plague)

伝播する呪い＆耐性低下死霊 DoT

敵を倒すと自動で近くへ伝染し、「疫病（Plague）」・呪い数増加・詠唱速度増加・死霊被ダメ上昇を供給し続ける非常に便利な呪い枠です。

血液抽出 (Rip Blood)

ボルト連動自動発動／回復マナ/庇護供給

「カオスボルト」から自動発動させることで、一切の手動クリックなしに大量の血液球からマナとヘルス・庇護（血生臭い暴食等）を補給し続けます。

さまよえる霊魂 (Wandering Spirits)

恐怖付与／霊歩回避DoT 補助

パッシブや装備シナジーに合わせて自動霊魂を周囲に維持し、毒・死霊・炎上付与数（柄杓用）やマナ回収量を底上げします。

獄炎のシェード (Infernal Shade)

炎上＆魔炎付与加速持続火ダメ

炎上・火炎鞭型でボスに張り付けて火ダメージと詠唱速度を伸ばしたり、状態異常種数を増やすサブスキルとして採用可能です。

飢える魂 (Hungering Souls)

取り憑き DoT／マリナ杖対応育成・特化

ウォーロックのマナ・死霊貫通とも相性が良く、ワンド マリナの失くした魂 と組んで「取り憑き」DoT の貫通率を大きく上げられます。

刈り取り (Harvest)

状態異常起爆・カオス連鎖近接ハイブリッド

基本的には純スペルで戦うため優先度低めですが、カオスボルトの近接連動や死の刻印・マナ回収用の限定ビルドでは使われます。

骨髄の破片 (Marrow Shards)

自傷状態トリガー（限定用途）物理スペル

リッチほど低ヘルス・出血軸と噛み合いませんが、貫通クリスペルの単発差し込みや「死の神髄」向けの自傷管理で使われることがあります。

爆発ゾンビ召喚 (Summon Volatile Zombie)

自爆ゾンビ特化用（限定用途）カオスゾンビ型

パッシブ「カオスフレイム」の火＆死霊ボーナスや冒涜のベールでミニオン捕食（庇護増）を行う「Zombie Warlock」変則型で起用されます。

骨のゴーレム召喚 (Summon Bone Golem)

ベール生贄用/壁（限定用途）ミニオン

通常はスキル枠の都合で入りませんが、冒涜のベールで高ヘルスミニオンを吸収して大庇護を作る耐久特化セットアップで検討されます。

スケルトン召喚 (Summon Skeleton)

冒涜のベール捕食用（限定用途）ミニオン

ミニオン職でないウォーロックでは主に冒涜のベール発動中に仲間を食べて攻撃力／庇護を伸ばすための特殊枠として扱われます。

6. Season 5（Patch 1.5）人気ビルド 3 選

Season 5 でも定番周回・高耐久で人気のウォーロック代表 3 アーキタイプです。

① 苦悩・地獄亀裂＆カオスボルト自動連鎖型（Torment Warlock）

快適エコー周回・死霊耐性スケール
  • 戦い方: 地獄亀裂 を置きながら走るだけで周囲へ「苦悩（Torment）」をばら撒き、同時に カオスボルト と 骨の呪い／血液抽出 が全自動で連鎖爆発します。
  • 核装備: 骨響のバルビュータ、苦悩の輪（または 狂える錬金術師の柄杓）、魂縒りの紐。
  • 代表構成: 地獄亀裂 / カオスボルト / 冒涜のベール / 骨の呪い / 肉体交換

② マラトロス・火炎鞭ウォーロック（Flame Whip Warlock）

両手剣軸・高単体火ダメージ
  • 戦い方: マラトロスの背骨（Spine of Malatros） で地獄亀裂から凄まじい威力の火炎鞭（Flame Whip）を生成し、カオスボルト・魔炎と合わせてボスを一気に焼き切ります。
  • 核装備: マラトロスの背骨、骨響のバルビュータ、血が足りぬ／生者の最期の歩み 等。
  • 代表構成: 地獄亀裂 / カオスボルト / 魂の宴 / 冒涜のベール / 肉体交換

③ 冒涜のベール＆死霊の炎チャネリング型（Profane Veil / Ghostflame）

要塞庇護＋無敵オーブ連打
  • 戦い方: クールダウン短縮を極めた 冒涜のベール で高頻度オーブ発射と無敵を回し、合間に 死霊の炎 や 地獄亀裂 でチャネリング保護を常時維持します。
  • 核装備: 誤ったワープ、骨響のバルビュータ、アトラリアの赤い指輪。
  • 代表構成: 冒涜のベール / 死霊の炎 / 地獄亀裂 / 魂の悪疫 / 肉体交換

7. ウォーロックの強さを支える 4 大メカニズム

① 攻撃メカニズム：多重呪い乗算＋死霊耐性スケール

「苦悩」「骨の呪い」「魂の悪疫」「死の刻印」等を同時付与してマスタリーの呪い 1 つにつき +4% 乗算を稼ぎつつ、上限超過の死霊耐性とクリ倍率（Acidbane 経由の苦悩クリ化）で DoT 火力を限界突破させます。

② 防御メカニズム：死霊耐性→庇護＆チャネリング軽減

「骨響のバルビュータ（上限超過含む死霊耐性 3% ごとに毎秒庇護 +1）」「冒涜のベール」「悪心の保護／ドゥームヘラルド」「死への熱狂」の組み合わせにより、数千〜万単位の庇護（ワード）を自動で張り直します。

③ マナ・回転：呪い数還元＆無詠唱トリガー

カオスボルトを地獄亀裂から自動発動させるとコストの大部分を節約でき、さらに地獄亀裂の呪い維持中マナ還元（Soul Stealer 等）やアイドル・ベルトの庇護／マナ再生で快適な連射を維持できます。

④ 快適性：自動索敵亀裂と緊急無敵ベール

敵の進行ルートへ地獄亀裂を 1 つ落とすだけで後方の雑魚を漏れなく掃除しつつ、ボスの致命的な詠唱が見えたら「冒涜のベール」または「肉体交換」で安全にやり過ごせるためストレスが極めて小さいです。
