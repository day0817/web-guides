パラディン（Paladin）完全ガイド

高い耐久性能と回復効果（Healing Effectiveness）の攻撃変換、そして Season 5 で話題の「ラディアントランス」や反射型（Reflectadin）まで幅広くこなすセンチネル上級職の最新ガイドです。スキル名・装備名は Last Epoch Tools 日本語版 への直接リンクになっています。

1. マスタリーの特徴・他職との差別化・固有パッシブ

パラディン固有パッシブ＆マスタリーボーナス（攻防一体の光・回復変換）

センチネルの基本パッシブに 20pt 投資してパラディンを選択すると、固有スキル 聖なるオーラ（Holy Aura） が解放され、以下のマスタリー固有パッシブボーナスを獲得します。

  • 基礎ボーナス①: ヘルス割合に応じた増加ダメージ（最大 +100%） — 高いヘルス維持をそのまま火力ボーナスへ転換します。
  • 基礎ボーナス②: 調和力（Attunement）1 ポイントにつき回復効果（Healing Effectiveness）+1% — 回復量とスキル威力の双方を伸ばします。
  • 攻防の独自メカニズム: パラディンはオーラやツリーで全耐性・ヘルス再生・ブロックを厚く確保できるだけでなく、癒しの手 や 審判 を通じて「回復効果（Healing Effectiveness）」そのものをスペルダメージ・近接ダメージ・ワード生成へ変換できる点が最大の特徴です。

3. パラディン固有スキル＆重要ノード

パラディンで解放される 5 つの固有スキルです。スキル名から直接 Last Epoch Tools 日本語版へ移動できます。

聖なるオーラ (Holy Aura)

必須オーラ常時＋発動倍増

スロットに入れておくだけで自身と味方に攻撃力・元素耐性等のパッシブ恩恵を与え、発動すると短時間その効果を倍増させます。ほぼ全ビルドの耐久と火力の下支えです。

重要ノードとシナジー
  • Shelter from the Storm / 耐性系ノード: 元素耐性を大量に稼ぎ、装備 Suffix をヘルスやアーマーへ回せます。
  • Flame Burst / Fiery Inquisition: 攻撃ヒット時にスタックを貯めて炎爆発を誘発し、火型ビルドのサブ火力を稼ぎます。
  • 攻撃/詠唱速度・クリ率・再生強化ノード: ビルドの属性（スペル/近接/反射）に合わせて細かく調整可能です。

希望の光印 (Symbols of Hope)

必須バフ自動生成・火/防御

周囲を周回する光の印（シンボル）を纏い、印の数に応じてヘルス再生・ブロック率・元素耐性・火ダメージ等を得るバフスキル。自動生成ルートにより、押さずに常時最大維持する運用が主流です。

重要ノードとシナジー
  • 自動生成＋最大スタック増加ノード: 手動詠唱の手間をなくし、常時最大数の光印を維持して安定耐久を確保。
  • ブロック・耐性・耐久強化系: Reflectadin や盾型ではブロック率・物理/元素防御の底上げとして極めて優秀です。
  • Divine Flare / 火属性付与系: 印を消費して大範囲火炎爆発を起こす攻撃運用への切り替えも可能です。

癒しの手 (Healing Hands)

回復・ワード・無敵移動回復効果スケール

範囲回復を降らせるスペルでありながら、ツリー次第で「無敵付きトラバーサル移動」「他スキル命中時の自動発動＋ワード変換」「近接火炎スマイト化（Seraph Blade / Cleric's Hammer）」へ化けるパラディン最強クラスの汎用スキルです。

重要ノードとシナジー
  • トラバーサル化（無敵移動ルート）: ボスの即死ギミック回避用の無敵移動スキルとして Radiant Lance 型等で採用。
  • ワード生成ノード: 過剰回復や発動時回復を大量のワード（Ward）へ変換し、実質ヘルスを何倍にも押し上げます。
  • Seraph Blade / Cleric's Hammer / Bane of Evil: 回復効果を攻撃ダメージへ変換し、近接やスペルのメイン火力にもなります。

ラディアントランス (Radiant Lance)

Season 5 主役スキル追加効力 500%ブロック / マナ変換

Season 5 で登場した聖なるビーム攻撃。標準では盾を要求し超過ブロック率（Uncapped Block Chance 1% ごとにダメージ 1% 乗算増加）で伸びますが、ノード次第で杖＋マナ軸・無敵聖遺物設置・火属性変換へ自在に変化します。

重要ノード一覧（LE Tools 日本語版準拠）
  • 黄金の聖遺物（Golden Reliquary）: 直接詠唱できなくなる代わりに、ラディアントランスを自動発射する無敵の聖遺物を設置（調和力で設置上限増）。
  • Cloudless Sky（盾不要・マナ変換）: 盾制限を解除して両手杖（精霊の木脈 等）を装備可能にし、ブロック率の代わりに最大マナでスケール。
  • 太陽光線（Sunbeam）: 基本ダメージを火属性へ変換し、帯電・雷耐性寸断をすべて発火・火耐性寸断へ変換。
  • 光のクレッシェンド / Eagle's Foot: 【神聖の霊威】を消費してダメージ・範囲を強化、または小型ランス 2 本を追加発射して雑魚殲滅力を大幅向上。
  • まばゆいイージス / まばゆい審問: ブロック効力に応じた雷スペルダメ加算（まばゆいイージス）や、ボス/レア命中時の 審判 自動発動（まばゆい審問）も選択可能。

審判 (Judgement)

聖なる大地・火 DoT回復効果スケール

地面を叩きつけて「聖なる大地（Consecrated Ground）」を生成し、範囲内の味方を回復しつつ敵へ火の持続ダメージを与えます。回復効果をフラットダメージへ変換するオーラ／DoT 型の定番です。

重要ノードとシナジー
  • Path of Judgement / Holy Trail 関連: 回復効果（Healing Effectiveness）を火炎持続ダメージへ直結させ、調和力積みがそのまま高火力になります。
  • Righteous Decree: 着弾時に 聖なる炎（Smite） を複数自動発動させる連携が可能です。

4. 最終ビルドで使用されうるセンチネル基本スキル（個別解説）

パラディンの最終ビルドでメイン攻撃・トリガー・無敵防御・移動バフとして組み込まれる全 12 のセンチネル基本スキルを個別に整理しています（即時避け（Evade） は共通回避枠のため省略）。

聖なる炎 (Smite)

S5 必須級スペルマナ循環・Devotion 連携

天から聖なる炎を落とし敵に火スペルダメ、周囲に回復を与えるスキル。Season 5 の Radiant Lance 型では「直接詠唱＋Time and Faith によるマナ回復＆献身のアミュレット（Devotion） の欠損マナ変換火力」を担い、Hammerdin やジャベリン型では自動トリガー火力として活躍します。

弾劾の護り (Rebuke)

Reflectadin 核心被ダメ大幅軽減チャネリング

チャネリング中あらゆる被ダメージを劇的に軽減し、終了時や被弾時に反撃・回復・マナ回復を得る鉄壁防御スキル。Season 5 の Reflectadin ではボス攻撃を棒立ちで耐えながら反射ダメージで倒す軸になります。

ハンマースロー (Hammer Throw)

Hammerdin 主力投擲・周回/発火

回転するハンマーを投擲する伝統主力スキル。自身の周囲を周回する螺旋ハンマー化や、火属性変換（Season 5 の Fire Hammerdin）、アイドル「投擲ヒット時スマイト発動」とのコンボで画面全体を制圧します。

ジャベリン (Javelin)

Battle Standard / 聖なる炎トリガー雷/火変換

槍を投擲するスキル。最終ビルドでは地面に旗を立てて自身と味方を強化する「Battle Standard（戦旗）」＋周囲へ自動 聖なる炎／雷槍を落とす運用や、Holy Trail（聖なる軌跡）の火 DoT 主力として使われます。

突進 (Lunge)

高速トラバーサル無敵・マナ回復・聖なる炎連動

敵へ一瞬で飛び込む移動攻撃スキル。癒しの手を攻撃・回復用に温存したい構成や、聖遺物を設置しながら高速移動したい Radiant Lance 電撃型で移動枠として採用されます。

仇討ち (Vengeance)

被ダメ軽減・反撃Reflectadin 採用

命中後に被ダメージ軽減バフ（Bolster）と反撃（Riposte）を得る 0 マナ近接スキル。Reflectadin でさらに被ダメを抑えつつ追加の装甲粉砕・回復・反撃を稼ぐ枠として採用されます。

旋風刃 (Warpath)

チャネリング移動攻撃聖なる炎トリガー可

回転しながら移動し続ける伝統のチャネリングスキル。パラディンでは火変換ルートや、回転中に「聖なる炎（Smite）」や「癒しの手」を自動トリガーし続ける快適周回ビルドの軸として使えます。

マルチストライク (Multistrike)

聖なる炎・発火トリガー0マナ近接

周辺の複数体へ追撃剣を飛ばす近接スキル。直接の剣撃と同時に 聖なる炎 を自動発射するノード（Smite on hit）と、Time and Faith のマナ/ヘルス回収を組み合わせる型で優秀です。

斬り捌き (Rive)

3段コンボ・癒しの手連動0マナ近接

3 撃目に確定クリティカルや引き寄せを乗せられる 0 マナの近接連撃。火属性・Ignite 型や、癒しの手（Seraph Blade） を近接攻撃ごとに自動発火させる近接パラディンの起点として機能します。

シールドチャージ (Shield Rush)

長距離高速移動盾要求

盾を構えて直線状に長距離を高速突進する移動スキル。敵のターゲットを必要としないため、マップを最速で駆け抜けたい高速ファーム型で「突進（Lunge）」の代わりに採用されます。

シールドバッシュ (Shield Bash)

スタン・ブロック関連盾要求

盾で敵を強打してスタンや装甲粉砕を与える近接スキル。ブロック率・ブロック効力を大量に確保する盾型パラディンで、敵の行動阻害や追加の近接発火・防御バフ枠として選択肢に入ります。

ヴォイドクリーヴ (Void Cleave)

確定クリ・トラバーサル両手武器/火変換

広範囲を斬り裂くトラバーサル近接スキル。火属性への変換や「次の攻撃を確定クリティカル化＋火ダメ加算」するノードを活かし、両手武器型パラディンの移動兼バースト補助として使われます。

6. Season 5（Patch 1.5）人気ビルド 3 選

Last Epoch Tools に掲載されている Season 5（Rage of the Frostborn）対応の公式ビルドガイドおよびプランナーに基づく代表 3 構成です。

① ラディアントランス・パラディン（Big Smite Little Smite）

S5 主役 / ボス＆マップ両立
  • 戦い方: ラディアントランス（Eagle's Foot / 黄金の聖遺物）で広範囲を掃討し、聖なる炎 で単体火力を叩き込みつつ Time and Faith でマナを回収します（BlueBeyond 版プランナー / Fire Radiant Lance プランナー）。
  • S5 注目点: 献身のアミュレット（Devotion） で欠損マナをスマイト基礎ダメへ変換し、精霊の木脈（Spirit Xylem） や 巨人の心臓（Titan Heart） で高い被ダメ軽減を得ます。
  • 採用スキル: ラディアントランス / 聖なる炎 / 希望の光印 / 聖なるオーラ / 癒しの手

② リフレクタディン（Reflectadin / 反射パラディン）

Season 5 ガイド掲載 / ハードコア対応
  • 戦い方: 目くらましの光の茂み（Thicket of Blinding Light） と 棘貝（Thornshell） を核に、敵が視認・攻撃するだけで反射ダメージが発生。ボス戦では 弾劾の護り を構えて棒立ちで耐え抜きます（LE プランナー）。
  • 強み: 調和力・物理耐性・反射ダメージを積むほど攻防が同時に伸び、操作が極めて楽でハードコア適性も非常に高いのが特徴です。
  • 採用スキル: 弾劾の護り / 希望の光印 / 聖なるオーラ / 癒しの手 / 仇討ち

③ ファイア・ハンマーディン（S5: Fire Hammerdin）

Season 5 プランナー / 快適周回
  • 戦い方: 火属性に変換した ハンマースロー を投擲しながら走り、投擲命中時アイドル等で 聖なる炎 を多段降下させる伝統の高回転ビルド。
  • 強み: 盾装備による高いブロック率と移動中の自動攻撃範囲が噛み合い、低予算からエンドゲームまで安定して伸びます。
  • 採用スキル: ハンマースロー / 聖なる炎 / 聖なるオーラ / 希望の光印 / 癒しの手（または 突進）

攻撃スケーリング

  • 調和力（Attunement）＋回復効果変換: 調和力 1 ごとに回復効果 +1% が付き、審判 や 癒しの手 の基礎ダメへ直結。
  • 超過ブロック / 最大マナ変換: ラディアントランス は超過ブロック率 1% ごとに 1% 乗算、または Cloudless Sky 採用時は最大マナでスケールします。
  • 反射スケーリング: Reflectadin は調和力・物理耐性・攻撃者への反射ダメージ（Flat Reflect）を積み上げて全敵を自動処理します。

防御レイヤー

  • 耐性確保の容易さ: 聖なるオーラ と Defiance で元素耐性を大幅に稼げるため、装備の自由度が全職トップクラスです。
  • ブロック＋アーマー＋回復/ワード: 高いブロック率＆ブロック効力、Armour Clad の近接被ダメ軽減、さらに 癒しの手 や アーケイロスのねじれた心臓 によるワード生成で二重三重の守りを作ります。
  • 直接カット手段: Rebuke の超高倍率軽減や、巨人の心臓／精霊の木脈 の被ダメ軽減を重ねます。

マナ維持の仕組み

  • Time and Faith サイクル: センチネル基本パッシブ Time and Faith により、聖なる炎 等の直接詠唱／近接ヒットでマナとヘルスを継続回復します。
  • 意図的な欠損マナ制御: 献身のアミュレット（Devotion） 型では「ラディアントランスでマナを削り→スマイトの欠損マナ火力を最大化しつつマナを戻す」循環を行います。
  • 無消費トリガー活用: 0 マナの近接や Hammer Throw＋自動 Smite でマナ枯渇を防げます。

快適性（QoL）・周回テンポ

  • 自動照準・自動設置: 「黄金の聖遺物」の聖遺物タレットや、Reflectadin の視認/被弾反射により、細かいエイムなしで高速クリア可能です。
  • 手動バフ管理が不要: 希望の光印（自動維持）＋ 聖なるオーラ（常駐）のおかげで操作が極めてシンプルです。
  • 無敵移動による安定感: 癒しの手 のトラバーサル化で安全にギミックを抜けられます。
