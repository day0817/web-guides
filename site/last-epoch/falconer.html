1. マスタリーの特徴・他職との差別化・固有パッシブ（隼）

ファルコナー固有パッシブ＆マスタリーボーナス（隼システム）

ローグの基本パッシブに 20pt 投資してマスタリーを選択すると、固有スキル 隼狩り（Falconry） が解放されて無敵の相棒「隼」が常時同行し、以下のマスタリー固有ボーナスを獲得します。

  • 基礎ボーナス: 基礎敏捷力（Dexterity）+12、および 総敏捷力 4 ポイントごとに隼の近接ダメージ +1。
  • 完全無敵の自動相棒: 隼は敵の攻撃対象にならず死亡しないため、ミニオン耐久への投資を一切せずに高コラプションでも安定したダメージ源・デバフ役として機能します。
  • 本体ステータスの継承（ハイブリッド設計）: 通常の召喚職（ネクロマンサー等）と異なり、プレイヤー自身の近接・投擲・弓・クリティカル・状態異常付与率・移動速度をパッシブやスキルノード経由で隼やバリスタへ変換できるため、本体と相棒が同時にスケールします。

3. ファルコナー固有スキル＆重要ノード

ファルコナーで解放される 5 つの固有スキルです。スキル名をクリックすると Last Epoch Tools 日本語版が開きます。

隼狩り (Falconry)

ミニオン・コンパニオン マナ 48 / CD 0s 敏捷力

無敵の隼を召喚し、使用時にターゲット範囲へ高速連撃「ファルコンストライク（Falcon Strikes）」を放ちます。敏捷力 1 ごとに隼ダメージ +4%（隼召喚ノード）を得る全ファルコナーの基盤です。

重要ノード一覧（LE Tools 日本語版準拠）
  • 手練れのハンター (1pt): プレイヤーの近接・投擲・弓の増加ダメージのうち最高値の 50% を隼に適用する最優先ブリッジノード。
  • ファルコナージャーニー (1pt): 隼のグローバルダメージが、プレイヤーのレベルと敏捷力 1 ごとに 1% 上昇。
  • 眼を狙え! (1pt) / 見え透いた弱点 (1pt): プレイヤーの追加クリティカル率の 50%、および攻撃タイプに応じたクリティカル乗数の 25%（10秒）を隼へ継承。
  • 引き裂く爪 (4pt): プレイヤーの出血・毒・各種寸断・鈍足付与率の 15%/pt を隼の攻撃にも適用。
  • ファルコナーの印 (3pt) / 疾風のファルコン (1pt): 印付きの敵へのダメージ増加＋印消費でファルコンストライクの CD 即時回復（マナコスト +40）。
  • 狩りの成果 (1pt): 隼のキルまたはボスヒット時に総能力値に応じてヘルスとマナを回復（3秒上限）。
  • 鳥類の精力 (4pt) / 隣り合わせ (3pt): 連撃回数 +1/pt と攻撃速度上昇、プレイヤー攻撃ヒット時の残り CD 3%/pt 短縮。
  • 毒の雨 (1pt) / フラスコ貯蔵 (4pt): 隼が 強酸のフラスコ を自動投擲（CD6秒・元マナ75%）。

ダイブボム (Dive Bomb)

主力範囲バースト マナ 20 / CD 5s 追加効力 500%

隼が上空から指定地点へ急降下して大爆発を起こす必殺スキルです。着地前に中断された場合はマナコストとクールダウンの 70% が回復します。

重要ノードとシナジー
  • On Wings of Shadow: スモークボム等で生成したシャドウ位置にも影の隼（Shadow Falcons）を降らせ、多段範囲バースト化します。
  • Rush of the Hunt: クールダウン回復速度を大幅に伸ばし、連打頻度を上げます。
  • Cloud Gatherer: スモークボム範囲内に着地すると煙幕持続時間が延長され、防御・シャドウ供給を維持します。
  • 出血消費／Featherfall 派生: 蓄積した出血スタックを一撃で起爆する DoT バーストや、着地追撃強化への分岐が可能です。

エアリアルアサルト (Aerial Assault)

トラバーサル移動・バフ ウィングバースト

隼に運ばれて目標地点へ飛翔し、着地時にウィングバーストを放つ主力移動兼シナジー発動スキル。バリスタ型のバフ起点、および レザーフォール（Razorfall） 型の自動攻撃トリガーとして必須級です。

重要ノードとシナジー
  • Tactician: 着地後、展開中の全バリスタの標的を着地地点周辺へ集中させ、攻撃速度増＋知力（Intelligence）に応じた乗算ダメージを付与します。
  • Skyward Swoop / Aerial Prowess: 隼ヒット時の CD 回復と移動・攻撃テンポを底上げします。
  • 羽爆風と影身の刃連携: レザーフォール 装備時は、敏捷力 20 ごとに 影身の刃 を追加発射します。

爆破罠 (Explosive Trap)

罠・CD短縮エンジン 弓/投擲変換可

爆発する罠を設置・投擲します。ダイブボムのクールダウンを高速回復させつつ、デバフやスラウド生成、冷気変換などを同時にこなすエンジン役です。

重要ノードとシナジー
  • Free Lofting Bird: 爆破罠が起爆するたびに隼スキル（ダイブボム等）の残り CD を回復し、高頻度発動を可能にします。
  • Blast Rain: 弓スキルへ変換し、弓の攻撃速度で空から罠を降らせます。
  • Trap Sprinkler / Automated Bombardment / Ash Compartment: 起爆時の追加罠ドロップと耐性低下を重ねます。

ネット (Net)

拘束・デバフ・移動派生

敵を拘束・鈍足化する網を投げます。ボスやレア敵への被ダメージ増加・出血補助のほか、後方跳躍による緊急回避や ネットトラップ（Net Trap） による罠自動発動としても活用されます。

4. 最終ビルドで使用されうるローグ基本スキル（個別解説）

育成だけでなく、エンドゲームの最終ビルドでメイン火力・防御レイヤー・機動・マナ回復枠として採用される全 11 のローグ基本スキルを個別に整理しています（即時避け（Evade） は共通回避枠のため省略）。

バリスタ (Ballista)

最終主力（S5 最有力）ミニオン・タレット

自動射撃タレットを設置します。ファルコナーの「エアリアルアサルト（Tactician）」や弓ユニーク エスリンの抵抗（Uethrin's Stand） と組むことで Season 5 屈指の高コラプション火力を発揮します。

最終ビルドでの採用ノード・役割
  • Armed Construction: 消滅・再設置時に爆発を起こし、敏捷力（Dexterity）に応じてダメージと爆発範囲が伸びます。
  • 最大設置数増加 ＋ Shared Enhancements / Practicality: 設置上限（6基以上）を増やし、プレイヤー自身のクリティカルや状態異常をタレットへ継承させます。

スモークボム (Smoke Bomb)

全ビルド共通の必須防御Silver Shroud / 影生成

煙幕を展開し、範囲内で Silver Shroud（確定回避＋ウォード）、Dusk Shroud、敵への盲目、さらにローグの「シャドウ（影）」生成を一手に担います。ZHP 型から耐久型までほぼ全ビルドで採用されます。

最終ビルドでの採用ノード・役割
  • Silver Shroud / Dusk Shroud 獲得ノード: 高コラプションの一撃死を防ぐ核心防御レイヤー。
  • シャドウ生成 ＋ ダイブボム連携: 煙幕内の影が「ダイブボム（On Wings of Shadow）」や「影身の刃」の同時発火トリガーになります。

縮地 (Shift)

高速移動・無敵回避影生成・手裏剣/フラスコ連携

指定方向へ瞬時にダッシュし、通過・開始地点の操作や無敵時間を得られる基本トラバーサルスキル。短剣 煙の織り手（Smoke Weaver） やシャドウ生成・手裏剣自動展開と組む構成で採用されます。

最終ビルドでの採用ノード・役割
  • 無敵ウィンドウ＋状態異常解除: 危険なボス攻撃のすり抜けとデバフ解除に有効。
  • 移動時自動トリガー: 移動中に「手裏剣投げ」や「強酸のフラスコ」・シャドウを自動展開し、移動＝バフ/攻撃化できます。

影身の刃 (Umbral Blades)

最終主力（Razorfall/影軸）投擲・刃爆発

刃を投擲して地面へ設置・回転・爆発させる投擲スキル。靴 レザーフォール（Razorfall） 採用時はエアリアルアサルトから自動展開され、シャドウダガー（Shadow Daggers） の主軸にもなります。

強酸のフラスコ (Acid Flask)

フラスコ連携・デバフマナ 10 / 投擲

毒瓶を投擲して範囲ダメージと毒・装甲粉砕を付与します。隼狩りの「毒の雨」「フラスコ貯蔵」を取ると隼自身がフラスコを投擲するようになるため、自身で連打せずとも自動発動させる専用構成が組めます。

デコイ (Decoy)

挑発・ヘイト分散爆発補助

敵を引きつけて爆破するおとりを設置します。高コラプションの ZHP バリスタ型やボス戦で敵のタゲを逸らし、安全な設置・攻撃時間を作る防御ユーティリティとして採用枠に入ります。

手裏剣投げ (Shurikens)

アーマー％バフ周囲回転・自動展開

投擲手裏剣を放ちます。最終ビルドでは「Blade Shield」ノードにより手裏剣を自身の周囲に周回させてアーマー大幅増加を得る防御バフ枠や、縮地トリガーによる自動ヒット源として使われます。

穿刺 (Puncture)

0マナ枠・出血付与Sapping Strikes 連携

マナ消費 0 の直線貫通攻撃（弓・近接両対応）。出血ファルコナーでの高速出血スタック付与や、パッシブ Sapping Strikes によるヘルス＆マナ回収エンジン、さらには弓型での 血のねぐら 連携で活躍します。

灰燼斬 (Cinder Strike)

0マナ枠・Oil Coating素手/弓バフ

火属性を含む基本攻撃スキル。Oil Coating スタックによる火ダメ・回避値・火耐性バフ目的や、ファルコンフィスト（Falcon Fists） を用いた素手型・0マナ連打型の主力として使われます。

疾風撃 (Flurry)

超高速連撃ヒット数トリガー

高速連続ヒットを叩き込む基本攻撃。ヒット数に応じてクールダウンを短縮する「隣り合わせ（隼狩り）」やマナ回収・出血スタック稼ぎを発動させるトリガー役として機能します。

嵐刃 (Bladestorm)

投擲・持続ヒットデバフ/出血補助

回転する刃を投げて持続的な多段ヒットを発生させるスキル。投擲タグを持つためファルコナーの投擲パッシブと噛み合い、継続的なヒット数稼ぎ・状態異常付与の補助枠として採用余地があります。

6. Season 5（Patch 1.5）人気ビルド 3 選

Last Epoch Tools 上で確認された Patch 1.5 / 1.5.2 対応プランナーおよび Season 5 メタ傾向に基づく代表 3 アーキタイプです。

① 爆発バリスタ・ファルコナー（Patch 1.5.2 Planner）

S ティア / 高コラプション
  • 戦い方: バリスタ の Armed Construction でタレット爆発を連発し、エアリアルアサルト の Tactician で着地先へ火力を集中。スモークボム で無敵と Silver Shroud を回します。
  • S5 注目点: 敏捷力＋知力を極限まで積む ZHP 構成や、Season 5 新ユニーク エターナルフォント（Eternal Font） で自動ポーション起動ループを組む Patch 1.5 派生プランナー が人気です。
  • 採用スキル: バリスタ / エアリアルアサルト / スモークボム / 爆破罠 / デコイ（または 隼狩り）
  • 核装備: エスリンの抵抗（Uethrin's Stand）、エターナルフォント（Eternal Font）、実験的「移動スキルでミニオン同行」靴

② ダイブボム＆爆破罠ファルコナー（LE Tools ビルド一覧）

範囲殲滅＋単体ボス
  • 戦い方: スモークボム でシャドウをばら撒き、爆破罠（Blast Rain＋Free Lofting Bird）の連続起爆で CD を短縮して ダイブボム（On Wings of Shadow）を連打します。
  • 強み: 隼自身がプレイヤーのクリティカル・投擲ダメージを継承するため装備が組みやすく、出血起爆型にも直撃クリティカル型にも寄せられます。
  • 採用スキル: ダイブボム / 隼狩り / 爆破罠 / スモークボム / エアリアルアサルト
  • 核装備: 勇気の鉤爪（Talons of Valor）、山の峰（Peak of the Mountain）

③ レザーフォール／影身の刃 高速周回型（Patch 1.5 Planner）

高速ファーム / S5 プランナーあり
  • 戦い方: ユニーク靴 レザーフォール（Razorfall） により エアリアルアサルト で飛び込むたびに 影身の刃 を自動展開し、雑魚集団を一瞬で薙ぎ払います（Patch 1.5 別バリエーション）。
  • 強み: 移動そのものが広範囲攻撃になるため、モノリス高速周回やシーズン要素の消化に極めて快適です。
  • 採用スキル: 影身の刃 / エアリアルアサルト / ダイブボム / 隼狩り / スモークボム（または 縮地）
  • 核装備: レザーフォール（Razorfall）、煙の織り手（Smoke Weaver）、嘆きの霜（Mourningfrost）

7. 攻撃・防御・マナ・快適性のメカニズム

攻撃スケーリング

  • 敏捷力（Dexterity）が万能軸: 隼狩り（+4%/pt）、ファルコナージャーニー、バリスタ（Armed Construction）、レザーフォール すべてが Dex で乗算的に伸びます。
  • 本人ステータスの継承: 「手練れのハンター」「眼を狙え!」「Finesse Them」「Shared Enhancements」等により、プレイヤー側のクリティカル率・倍率・投擲/弓ダメージが隼やバリスタへそのまま乗ります。
  • シャドウ多重ヒット: スモークボム 等で影を複数配置し、ダイブボムや影身の刃で同時発火させることで単体火力も跳ね上がります。

防御レイヤー

  • Silver Shroud ＆ Dodge（回避）: Dex による高回避率に加え、スモークボムやパッシブ（Coordinated Fade）で Silver Shroud を維持し、確定回避＋ウォードで一撃死を防ぎます。
  • Glancing Blow ＆ 移動時軽減: Poise（Glancing Blow）と Evasion（移動中ダメ軽減）、さらに手裏剣の Blade Shield（アーマー増）を組み合わせます。
  • ZHP 特化時の注意: 高コラプション特化の ZHP 型はヘルス・耐性を切る代わりに「スモークボム無敵＋手動回避」前提となるため、通常プレイではヘルス・耐性75%・クリ回避を確保します。

マナ維持の仕組み

  • 消費の重いスキル群: バリスタ連打や爆破罠・疾風のファルコン（+40 マナ）はマナ消費が重いため供給手段が必須です。
  • Season 5 エターナルフォント軸: アミュレット エターナルフォント（Eternal Font） が毎秒自動でポーション使用を発動し、ベルトの実験的アフィックス「ポーション使用時マナ回復」で半永久ループを組めます。
  • 通常構築での回復手段: 隼狩りの「狩りの成果」、ローグ「Sapping Strikes（0マナスキル命中時回復）」、ベルトのポーション回復、指輪/アミュレットのマナ回復速度で補います。

快適性（QoL）・周回テンポ

  • ミニオン同行（実験的靴アフィックス）: 「移動スキル使用時にミニオンを同行させる（Minions Transported with Traversal Skills）」靴により、エアリアルアサルト で着地した場所へバリスタを瞬間移動させられます。
  • 常時 Haste（迅速）: 「Agility」「Raptor's Wings」「目覚めの翼」等で攻撃・移動速度バフが途切れず、走破性が極めて快適です。
  • CD 短縮の噛み合わせ: クールダウン回復速度（CDR）と Free Lofting Bird（罠起爆で隼 CD 短縮）を積むことで待ち時間ストレスが消えます。
