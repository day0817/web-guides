1. マスタリーの特徴・他職との差別化・固有パッシブ

ヴォイドナイト固有パッシブ＆マスタリーボーナス（エコー複製＋虚無特化）

センチネルの基本パッシブに 20pt 投資してヴォイドナイトを選択すると、固有スキル 消滅波（Erasing Strike） の解放ルートが開き、以下のマスタリー固有ボーナスを獲得します。

  • 基礎ボーナス①: 近接虚無ダメージ +75% — 物理ベースの武器攻撃へ虚無属性を乗せる下地を作ります。
  • 基礎ボーナス②: エコー発生率 10% — 近接・投擲・虚無スペルの攻撃が 0.5 秒後に影（エコー）として追加マナ消費なしで再発動します（一部移動スキルや特異点を除く）。
  • 虚無＆時間メカニズム: パッシブ「反響する攻撃」「時の軍勢」「後悔の権化」でエコー率を大幅に上乗せし、さらに「未来の心」でエコー発生ごとにマナ回収、状態異常「老廃（Time Rot）」で継続ダメージと敵への被ダメ増加を重ねるのが最大の特徴です。

3. ヴォイドナイト固有スキル＆重要ノード

ヴォイドナイトで解放される 5 つの固有スキルです。エコー発生・時間歪曲・虚無デバフと直結しています。

消滅波 (Erasing Strike)

解放スキル / S5 主力エース高威力近接・虚無ビーム連鎖

巨大な武器を振り下ろして敵を抹消し、撃破時やスキル内の亀裂（Rift）効果で広範囲へ連鎖爆発やヴォイドビームを発生させるヴォイドナイトの象徴スキル。マナを大量に積むほど本領を発揮します。

重要ノードとシナジー
  • Essence of the End（マナ回収）/ 亀裂展開ノード: 重いマナ消費を補いつつ、着弾地点から遅れて再爆発する Void Rift を複数生成します。
  • 四海裂き（World Splitter） 連携: 最大マナ量と消滅波スキル補正・確定クリ倍率により、単発数百万〜億単位のバーストを出します。
  • ヴォイドクリーヴ連動: クリーヴで移動直後に消滅波を撃つことで、強制クリティカル＆追加ダメージを乗せられます。

貪りのオーブ (Devouring Orb)

全構成必須エンジン自周囲周回・裂け目誘発

自身を追従・周回しながら一定間隔で虚無ボルトと裂け目（Void Rift）を発生させるオーブを召喚します。周囲の敵へ自動攻撃・老廃付与・装甲粉砕を続け、近接型からスペル型まで必須級の 1 枠です。

重要ノードとシナジー
  • Hollow Orb（自周囲周回化）: 地面設置ではなく自キャラにくっついて回るため、移動中ずっと周囲を自動攻撃・バフし続けます。
  • Abyssal Emission / Void Rift 強化: 深淵のエコー 連動や虚無ダメージ増・移動速度バフ等をまとめて稼げます。

深淵のエコー (Abyssal Echoes)

S5 クリティカル主砲 / 連鎖デバフ老廃・被ダメ増

自身から虚無の衝撃波を放ち、命中した敵がさらに周囲へ次々とエコーを連鎖爆発させます。他スキル（ヴォイドクリーヴ等）からの自動トリガー枠だけでなく、Season 5 ではスペルクリティカル型メイン火力としても人気です。

重要ノードとシナジー
  • Voracious / Screaming Rifts: エコー連鎖範囲・老廃（Time Rot）確率・敵の被クリ/被ダメ増加を広範囲にばら撒きます。
  • クリティカル直接詠唱ルート: S5 ガイド では高い詠唱速度とクリ率・「混沌の残響」を積んで直接連打する主砲として使われます。

特異点 (Anomaly)

必須級バフ・時間停止クリ率・攻撃/詠唱速度増

時間泡（Time Bubble）を展開して敵を時間停止させ、同時に自身へ大幅なクリティカル率・攻撃/詠唱速度・ヘルス/シールド・虚無ダメージバフを付与する超強力サポートスキルです。

重要ノードとシナジー
  • Time Bubble 即時化（Time Lord 等）: 時間停止を省いて即座に自身の周囲へバフ泡を展開し、ボス戦での瞬間火力を最大化します。
  • マーク（Mark of Rot）＋吸命: バブル範囲内の敵へ継続ダメージ・虚無耐性低下を与え、近接/スペル両方の火力を底上げ。

ヴォイドリバース (Volatile Reversal)

時間巻き戻し・瞬間移動攻防リセット・デバフ

数秒前の自分の位置・ヘルス・マナへ時間を巻き戻し、同時に通過地点・出現地点へ虚無の裂け目と攻撃/詠唱速度・敵被ダメージ増加デバフを発生させる時間操作スキルです。

重要ノードとシナジー
  • 敵への虚無・継続被ダメ増加: ボス戦での最大バースト直前に使うことでダメージ効率を大きく引き上げられます。
  • 引き戻し制御 / クールダウン管理: 立ち位置を変えすぎたくない構成では、位置巻き戻しを抑えつつ速度バフと裂け目だけを得る調整も可能です。

4. 最終ビルドで使用されうるセンチネル基本スキル（個別解説）

ヴォイドナイトの最終ビルドで主力攻撃・移動連携・エコー母体として採用されうる全 12 のセンチネル基本スキルを個別に解説しています（共通回避 即時避け（Evade） は除く）。

ヴォイドクリーヴ (Void Cleave)

消滅波型の必須相棒トラバーサル・確定クリ連動

前方へ踏み込んで大きく斬り払う移動近接スキル。消滅波（Erasing Strike）型では次の消滅波を確定クリティカル＋高倍率化するノードや、斬撃後に自動で「深淵のエコー」を発動するノードにより攻防移動の要になります。

旋風刃 (Warpath)

S5 虚無スピン主力老廃・エコー・0マナ可

回転移動し続ける定番チャネリング。ヴォイドナイトでは虚無属性への変換（Echoing / Void Spiral）＋ 0 マナ維持＋高速エコー発生により、走りながら画面中の敵を老廃（Time Rot）や虚無斬撃で切り刻めます。

聖なる炎 (Smite)

虚無変換スペル化エコー / 旋風刃・投擲連動

本来は火スペルですが、ツリー内で虚無属性（Atonement / Void 変換）へ変換でき、ヴォイドナイトのエコー発生やパッシブ「自制」と噛み合います。投擲型・スピン型の自動追撃としても優秀です。

突進 (Lunge)

敵指定高速移動無敵・マナ回復

敵への高速接近手段。移動時の無敵フレームやキル時のクールダウンリセット、ヘルス/マナ回復を得られ、両手武器型以外で機動力と安定感を両立したい際に採用されます。

シールドチャージ (Shield Rush)

高速周回移動盾型向け

盾を構えた無ターゲット突進スキル。深淵のエコー型や老廃型など片手武器＋盾を装備するヴォイドナイトで、マップ踏破速度を最速にする移動枠として活躍します。

斬り捌き (Rive)

0マナ虚無連撃エコー / 時と信仰

3 撃目に確定クリ・虚無変換・引き寄せを持つ 0 マナ連撃。エコーとの組み合わせで 3 撃目連打や、パッシブ「時と信仰」によるヘルス/マナ回復用として扱いやすい基本攻撃です。

仇討ち (Vengeance)

被ダメ軽減・虚無対応0マナ近接

被ダメージ軽減バフ（Bolster）を得ながら戦える 0 マナ近接スキル。近接殴りの耐久底上げと「時と信仰」でのマナ戻しを両立したい堅実な型で採用されます。

マルチストライク (Multistrike)

多段近接・虚無変換スマイト連動0マナ

追撃剣による手数と「聖なる炎（虚無変換）」自動誘発に優れた近接スキル。エコー発生と合わせた多段トリガーで老廃やヒット時効果を大量にばら撒けます。

ハンマースロー (Hammer Throw)

投擲エコー・虚無変換遠距離周回

ヴォイドナイトの「投擲攻撃もエコー発生する」「時の軍勢（投擲速度増）」を活かせる投擲主力。虚無変換ルートやスマイト（虚無変換）発動型で安全に戦えます。

ジャベリン (Javelin)

投擲・移動・旗バフ老廃付与候補

槍投げによる遠距離投擲やトラバーサル移動、戦旗設置を行えるスキル。投擲型ヴォイドナイトの補助やエコーと合わせた手数稼ぎに使えます。

弾劾の護り (Rebuke)

緊急ダメージカットマナ/ヘルス回復

チャネリング中の圧倒的被ダメ軽減スキル。ボスの大技を耐えつつマナとヘルスを一気に戻したい防御重視のビルドで差し込むことができます。

シールドバッシュ (Shield Bash)

スタン・ブロック型向け盾要求

盾装備時のスタン＆アーマー粉砕近接スキル。パッシブ「ただひとつの目的」はブロック率 30% 未満で効果倍増するため通常は両手武器か低ブロック盾を好みますが、ブロック特化構成では候補になります。

7. 攻撃・防御・マナ・快適性のメカニズム

攻撃スケーリング

  • エコー発生率＝実効火力の倍増: マスタリー 10% に加えパッシブでエコー率を盛ることで、ほぼすべての攻撃が 0.5 秒後に無料複製されます。
  • 「ただひとつの目的」＋老廃（Time Rot）: ブロック率 30% 未満維持で高倍率虚無ダメージを得つつ、老廃スタックによる継続ダメ＆敵被ダメ増を重ねます。

防御レイヤー（高ヘルス＋虚無吸収）

  • 生命力（Vitality）特化の高ヘルス＋吸収: 生命力ノード（「永遠なる姿」等）と「世界を喰らうもの」「終わりなき飢え」の虚無ダメージヘルス吸収により、1 ヒットで全快級のリカバリーを持ちます。
  • 両手軽減＋虚無のイージス: 巨人の心臓（被ダメ15%減）、装甲硬化、「虚無のイージス」や 貪欲なる虚無 で大ダメージを耐えます。

マナ維持の仕組み

  • 未来の心＋Void Well（周期回復）: エコー発動時のマナ回復や、最大マナを増やすほど周期回復量が増えるパッシブ機構により、消滅波の高コストを支えます。
  • 0マナ移動＆時間巻き戻し: ヴォイドリバースによるマナ巻き戻しや、消滅波ツリー内のマナ回収ノード（Essence of the End）を組み合わせます。

快適性（QoL）・周回テンポ

  • 貪りのオーブ自動展開: 1 度回せば周囲を自動で叩き続け、移動速度バフまで乗ります。
  • 1〜2 スキル主体の明快な操作: 旋風刃スピン型やヴォイドクリーヴ→消滅波ループは、スマホから見返しても操作手順が非常にシンプルです。
