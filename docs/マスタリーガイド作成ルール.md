# Last Epoch マスタリーガイド作成ルール

本ドキュメントは、`site/last-epoch/falconer.html` を基準として、他のマスタリー（ブレードダンサー、マークスマン、他クラス）へ統一品質で展開するための標準設計ルールです。

---

## 1. ファイル配置とパス規約

- **配置先**: 公開ページは必ず `site/last-epoch/<mastery-slug>.html` に配置する（例: `falconer.html`, `bladedancer.html`, `marksman.html`）。
- **ハブ導線更新**: 新規ページを作成したら、必ず以下の 2 箇所を更新する。
  1. [site/last-epoch/index.html](../site/last-epoch/index.html) のマスタリー一覧カード（`card--muted` から `a.card` リンクへ昇格）および右下ドロワー `#nav-drawer` の `.nav-list`。
  2. 新設ページ自身のパンくず（`WebGuides / Last Epoch / <マスタリー名>`）と右下ドロワー `#nav-drawer`。
- **相対パス厳守**: GitHub Pages サブディレクトリ配信（`https://<user>.github.io/<repo>/`）で 404 を防ぐため、CSS・JS・ページ間リンクはすべて `../assets/base.css`・`./index.html` 等の相対パスで記述する（`/` 始まり禁止）。

---

## 2. 最新情報・名称翻訳ルール（Last Epoch Tools 準拠）

1. **対象シーズンの固定**: ページ冒頭（`page-eyebrow`・`page-lead`・メタ注記）に「対象シーズンおよびパッチ（例: `Season 5: Rage of the Frostborn / Patch 1.5系`）」を明記し、旧シーズンの陳腐化した仕様を混ぜない。
2. **Last Epoch Tools 日本語版の名称優先**:
   - スキル・パッシブ・ノード・ユニーク装備の名称は `lastepochtools.com` の日本語ルート（`/skills/ja/<slug>`, `/db/ja/items/<id>`）で確認した公式日本語訳を使用する。
   - 表記は原則 **「日本語名（英語原名）」** を併記する（例: `ダイブボム（Dive Bomb）`）。英語ツール・海外攻略との照合を容易にするため。
3. **未確認数値の捏造禁止**:
   - 実測や公式データで確認できていない数値・DPS・ドロップ率は断定記載せず、確認できた仕様・倍率のみを記載する。
4. **詳細リンクの埋め込み**:
   - スキル・パッシブツリー・装備・ビルドには `lastepochtools.com`（日本語ルート `/skills/ja/...`, `/db/ja/...`, `/planner/ja/...` 等）への外部リンク（`.le-link`、`target="_blank" rel="noopener noreferrer"`）を付与する。

---

## 3. 視覚表現・アイコン規律（画像直リンク禁止）

- `lastepochtools.com` のスキル／アイテム画像は巨大 CSS スプライトシートかつ Cloudflare により外部直リンク（`Referer` 付与）が `403` でブロックされるため、**外部サイトの画像 URL への `<img src="...">` 直リンクは行わない**。
- Unicode 絵文字（🔥, ⚔️ 等）も使用禁止とし、役割別（物理攻撃・トラップ・移動/防御・パッシブ・装備・ビルド）の **インライン SVG アイコン（`currentColor`）**＋ `.skill-icon-box` ＋ テキストカード UI で視認性を確保する。
- 独自画像を配置したい場合のみ、`site/assets/images/` 配下へ権利クリア済みアセットを置いて相対パス参照する。

## 4. 標準 7 セクション構成（スマホ優先情報設計）

1ページ内の縦スクロール過多を防ぐため、**「要約カード ＋ `<details>` 折りたたみ ＋ LE Tools 詳細リンク」** の 3 層構造で以下の 7 セクションに統一する。

1. **ヘッダー＋目次ピル（`.page-header` + `.toc-pills`）**
   - 対象シーズン、マスタリーの立ち位置（強み・適性）、ページ内セクションへのジャンプボタン。上部固定ヘッダーは置かない。
2. **基本クラス前半〜序盤育成（ローグ等ベースクラス連携）**
   - 序盤レベリングの主力スキル・移動/防御スキル（日本語名＋英語名・マナ/CD・役割）とベースクラス重要パッシブ。
3. **マスタリー固有スキル＆重要ノード（`<details>` 折りたたみ）**
   - マスタリー固有 5 スキル＋主力ベーススキルの役割カード。全ノード網羅はせず、シーズン現環境で採用率の高い核心ノード・シナジーを `<details class="node-details">` に格納し、全ノード確認は LE Tools リンクへ誘導。
4. **パッシブツリー指針（ベースクラス ＋ マスタリー）**
   - 序盤〜終盤の振り方方針と、火力・防御・リソース変換の核となるパッシブを `.table-scroll` 表またはカードで整理。
5. **最新シーズン人気ビルド（代表 3 アーキタイプ）**
   - プレイスタイル（高速周回 / ボス・高コラプション / 快適・安定等）、使用スキル、キーユニーク、LE Tools プランナー／ガイドリンクを `.build-card` で比較提示。
6. **4 大メカニズム解説（攻撃・防御・マナ・快適性）**
   - `.mech-grid`（2 列/スマホ 1 列）で、スケーリング式・生存レイヤー・マナ維持ループ・移動/快適性（QoL）を整理。
7. **人気装備・ユニーク＆アフィックス優先度**
   - 主要ユニーク装備（入手先・コア効果・LP 優先度・LE Tools DB リンク）と、部位別アフィックス優先表（`.table-scroll` 必須）。

## 5. スマホ UI・検証チェックリスト

- [ ] `base.css` と `nav.js` のみで動作し、外部 CDN 依存がないか
- [ ] 幅 `390px`（iPhone 等）でページ全体の横スクロール（`scrollWidth > innerWidth`）が `0` か
- [ ] すべての `<table>` が `<div class="table-scroll">` で囲まれているか
- [ ] ボタン・目次ピル・`<summary>`・`.nav-link` のタップ領域が高さ `44px` 前後以上確保されているか
- [ ] Unicode 絵文字が使われておらず、アイコンがすべてインライン SVG か
- [ ] `lastepochtools.com` リンクに `target="_blank" rel="noopener noreferrer"` が付与されているか
